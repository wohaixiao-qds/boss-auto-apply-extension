# BOSS 自动打招呼侧边栏插件

这是一个基于 Chrome Manifest V3、WXT、React、TypeScript 和 Radix Themes 的本地 Chrome 扩展。

插件通过 Chrome Side Panel 工作，不会在 BOSS 页面注入浮层或覆盖页面内容。用户在 BOSS 职位列表中完成筛选后，从浏览器右侧打开插件，扫描职位、审核列表，再按顺序执行打招呼。

## 主要功能

- 按用户设置的单批投递上限滚动收集当前 BOSS 搜索结果，上限可在 `1-150` 之间输入。
- DOM 决定当前搜索结果中的可见职位、列表顺序和职位 ID，职位列表接口仅按精确 ID 校正公司、岗位、薪资和城市。
- 接口中存在但当前页面没有展示的职位不会进入投递队列。
- 自动排除岗位未识别、岗位与公司/城市重复、职位链接无效、已沟通、外包和猎头岗位。
- 发送前展示公司、岗位、薪资和城市，用户审核后再确认开始。
- 当前列表中能精确匹配职位卡时优先使用列表原生控件；否则打开经过校验的职位详情页发送。
- 单个职位失败会进入失败分类并继续下一条；验证码、登录失效、频率限制和每日上限等硬阻断会暂停任务。
- 支持待投递、投递成功和投递失败分类，以及暂停、继续、停止和移除职位。

## 本地运行

要求 Node.js 20 LTS 或更高版本。

```bash
npm install
npm run build
```

生成给他人安装的免费 ZIP 包：

```bash
npm run package
```

ZIP 会生成在 `release/boss-auto-greeting.zip`。对方解压后，在 `chrome://extensions/` 开启开发者模式，选择解压后的、直接包含 `manifest.json` 的文件夹。

然后在 Chrome 中：

1. 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目的 `.output/chrome-mv3` 目录。
5. 打开已登录的 BOSS 直聘职位列表，点击扩展图标打开侧边栏。

开发期间可以使用：

```bash
npm run dev
npm run typecheck
npm test
```

## 使用流程

1. 登录 BOSS 直聘并进入职位列表页。
2. 在 BOSS 页面设置城市、关键词、薪资和经验等搜索条件。
3. 点击扩展图标打开侧边栏，在投递设置中配置外包/猎头过滤和 `1-150` 的单批投递上限。
4. 点击“按上限收集职位”。插件会滚动当前搜索结果，直到符合条件的职位达到上限或没有更多职位。
5. 审核侧边栏中的公司、岗位、薪资和城市，可移除不需要投递的职位。
6. 点击“同意并按顺序发送”，确认后开始任务。
7. 任务期间可暂停、继续或停止，并可切换查看待投递、投递成功和投递失败列表。

## 扫描与发送规则

- DOM 用于确定当前页面实际展示的职位、列表顺序和职位 ID。
- BOSS 职位列表接口只用于校正同一职位 ID 的公司、岗位、薪资和城市，不会加入接口独有职位。
- 岗位无法识别、岗位等于公司或城市、岗位内容像薪资、职位 URL 无效或 URL 中 ID 不一致时会被排除。
- 数字列表短 ID、公司主页链接和其他非职位详情链接不会作为投递目标。
- 当前列表存在精确职位卡时优先使用列表原生沟通控件，否则打开经过校验的职位详情页。
- 只点击明确的“立即沟通”“打招呼”等控件；“继续沟通”“已沟通”等状态会归类为已处理并跳过。
- 发送后检查按钮状态、BOSS 成功提示和聊天页跳转，最长等待约 15 秒。
- 只有详情页加载或控件连接等未点击失败会重试一次；点击后结果不明确时不会自动重投，避免重复打招呼。

## 任务状态

- 待投递：已扫描但尚未处理。
- 投递中：当前正在处理。
- 投递成功：已检测到 BOSS 原生页面的成功结果。
- 投递失败：页面加载异常、按钮不可用或发送结果无法确认。
- 已跳过：职位已经沟通过或不满足投递条件。

## 当前实现边界

- 只使用本地 Chrome Storage，不接入后端或 AI。
- 打招呼操作复用 BOSS 页面已有的默认话术。
- 发送前需要在侧边栏审核并点击确认。
- 扫描只覆盖当前 BOSS 搜索条件下的结果，不会自动修改城市、关键词、薪资或经验等搜索条件。
- 扫描时按单批投递上限滚动收集职位，并排除无效职位目标以及用户启用的外包、猎头过滤项。
- 任务按职位列表顺序执行，并使用随机间隔和单批上限。
- 检测到验证码、登录失效或平台频率限制时自动暂停。
- BOSS 页面 DOM 结构变化时，需要更新 `entrypoints/boss.content.ts` 中的识别选择器。

## 更新扩展

更新代码并重新构建后，需要在 `chrome://extensions/` 中点击扩展卡片的“重新加载”。旧任务数据保存在 Chrome Storage 中；版本更新涉及扫描或职位识别逻辑时，应先在侧边栏清除旧任务，再重新扫描，避免继续使用更新前的职位数据。

## 注意事项

- 使用前请保持 BOSS 账号处于登录状态。
- 任务执行期间不要频繁刷新或手动切换 BOSS 页面。
- 插件不自动处理验证码、登录失效、频率限制或每日沟通上限，检测到这些情况时会暂停任务。
- 插件数据仅保存在浏览器本地，不连接外部 AI 或后端服务。
- Chrome 系统通知受操作系统通知权限、勿扰模式和浏览器设置影响。
- 构建时 Radix Themes 可能输出 `use client` 被忽略的提示，不影响扩展构建和运行。
